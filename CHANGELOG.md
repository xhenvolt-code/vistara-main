# Changelog

Notable changes to Vistara are recorded here. Versions follow
[Semantic Versioning](./README.md#versioning-and-releases), and each release
version is represented by a `vx.y.z` Git tag pointing to its release commit.

## 0.1.0 - 2026-10-28

Initial versioned repository baseline. This is an early streaming-platform
foundation, not a declaration of production readiness.

- Added the Next.js application, authentication flows, and responsive catalogue.
- Added Neon/Prisma-backed catalogue and admin control-room foundations.
- Added MarzPay collection and callback reconciliation foundations.
- Added admin-managed revenue-share allocations, reinvestment preferences, and
  reviewed payout-request records.
- Documented that live payments, payout transfers, media upload, and playback
  are not verified or fully operational.
